# OpenJM Workspace

White-label, self-hosted workspace platform. Implementation is in progress from the supplied Astra build handoff.

The first pass targets a Next.js web application, a dedicated Fastify API, PostgreSQL tenant isolation, BlockNote/Yjs collaboration, structured databases and boards, private file storage, and signed integration events.

This repository is not yet a production release. Build instructions and the verified acceptance report will be added with the implementation.
